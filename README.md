# 🎮 Игра "Угадай число"

Консольная игра на Go, в которой нужно угадать случайное число за ограниченное количество попыток.

## 🚀 Возможности

- 🎯 Три уровня сложности (Easy, Medium, Hard)
- 🔥 Система подсказок (Холодно/Тепло/Горячо)
- 🎨 Цветной вывод в терминале
- 📝 Сохранение истории игр в JSON файл
- 📊 Отображение всех попыток после игры
- ✅ Проверка корректности ввода

## 📦 Установка и запуск

### Требования
- Go 1.16 или выше

### Запуск
```bash
go run main.go
```

### Компиляция
```bash
go build main.go
./main
```

## 🎲 Как играть

1. Выберите уровень сложности:
    - **Easy**: числа 1-50, 15 попыток
    - **Medium**: числа 1-100, 10 попыток
    - **Hard**: числа 1-200, 5 попыток

2. Вводите числа в указанном диапазоне
3. Получайте подсказки после каждой попытки:
    - 🔥 Горячо (разница ≤5)
    - 🙂 Тепло (разница ≤15)
    - ❄️ Холодно (разница >15)

4. Угадайте число до окончания попыток!

## 📊 Сохранение результатов

Все игры сохраняются в `results.json` с информацией:
- Дата и время игры
- Результат (победа/поражение)
- Количество попыток
- Уровень сложности
- Загаданное число
